# IBERMEL EXPORT — web estática trilingüe

Web corporativa y catálogo demostrativo para IBERMEL EXPORT, en español, inglés y árabe.

## Qué funciona
- Diseño adaptable a móvil, tableta y ordenador.
- Selector de idioma ES / EN / AR con dirección de lectura RTL para árabe.
- Catálogo de productos y formatos.
- Cesta de compra con cantidades y subtotal, guardada en el navegador.
- Resumen de pedido descargable mediante copiar/pegar.
- Formulario de contacto que abre el cliente de correo predeterminado.

## Importante
Esta versión **no procesa pagos reales** y no envía pedidos a la empresa. No se ha inventado correo, teléfono, NIF, domicilio legal ni cuenta bancaria. El checkout genera una solicitud local para copiar. Los precios de azahar y tomillo están pendientes y esas variedades se muestran como próximas / precio por confirmar.

Los precios cargados del catálogo del proyecto:
- Miel multifloral ibérica: 250 g 3,50 €; 500 g 6,50 €; 1 kg 11,00 €.
- Miel de romero: 250 g 4,50 €; 500 g 8,00 €.

Son precios del proyecto y deben confirmarse antes de vender públicamente.

## Probar en tu ordenador
1. Extrae el ZIP en una carpeta.
2. Abre `index.html` con Chrome, Edge o Firefox.
3. Prueba el selector de idioma, añade productos y abre la cesta.

No necesita instalación ni dependencias. Para evitar limitaciones del navegador con algunas funciones, también puedes ejecutarla con un servidor local sencillo.

## Publicarla gratis en GitHub Pages
1. Crea una cuenta en GitHub si aún no tienes una.
2. Crea un repositorio nuevo, por ejemplo `ibermel-export-web`.
3. Sube **el contenido de esta carpeta** al repositorio (no solo el ZIP): `index.html`, `styles.css`, `app.js`, `assets/`, `README.md` y `PRIVACY-AND-LEGAL.md`.
4. En el repositorio, entra en **Settings → Pages**.
5. En **Build and deployment**, selecciona **Deploy from a branch**.
6. Selecciona la rama `main` y la carpeta `/ (root)`, guarda.
7. Espera a que GitHub Pages publique el sitio. La URL suele ser `https://TU-USUARIO.github.io/ibermel-export-web/`.
8. Abre la URL y comprueba todos los idiomas y el proceso de cesta.

GitHub Pages ofrece alojamiento estático gratuito, sujeto a sus condiciones y límites. Los nombres exactos de los menús pueden variar.

## Para vender de verdad
Para cobrar online hacen falta un proveedor de pagos y una integración segura, además de gestionar pedidos, inventario, impuestos, envío, devoluciones y avisos legales. No introduzcas datos de tarjeta en esta demo. Puedes mantener GitHub Pages para la web informativa, pero el checkout real suele necesitar una plataforma de comercio electrónico o un backend seguro.

## Antes de publicar
- Sustituye o añade el logo original si lo tienes.
- Confirma la denominación legal exacta, NIF, domicilio social y correo de empresa.
- Confirma los precios, stock, impuestos, transporte y territorios de venta.
- Revisa el aviso legal, privacidad, cookies y condiciones de compra.
- Añade fotos reales de producto solo si representan exactamente los productos que se venden.
